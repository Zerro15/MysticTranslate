# MysticTranslate

Русский перевод китайских Android-игр поверх экрана. MysticTranslate использует системный захват экрана, китайский OCR и китайско-русскую модель Google ML Kit. У приложения есть редактируемый профиль «Повелитель тайн» (诡秘之主).

## Установка на POCO X8 Pro

1. Откройте [Releases](https://github.com/Zerro15/MysticTranslate/releases) и скачайте APK. Доступна также [локальная сборка](#сборка).
2. Откройте APK на телефоне. Если HyperOS попросит разрешение на установку из этого источника, разрешите его приложению, из которого открыли файл. После установки разрешение можно отозвать.
3. Откройте MysticTranslate и нажмите **Загрузить офлайн-модели**. Дождитесь подтверждения. Для первого скачивания нужен интернет.
4. Выберите **Диалоги внизу** или **Весь экран**. Нажмите **Начать перевод** и разрешите показ поверх других приложений. Вернитесь в MysticTranslate и повторно нажмите **Начать перевод** для системного запроса захвата. Если Android предлагает выбор области, выберите весь экран.
5. Переключитесь в игру. **Стоп** прекращает перевод и захват. Если плавающие кнопки скрыты, используйте системный индикатор захвата или действие **Остановить** в уведомлении.

Названия системных пунктов различаются между версиями и регионами HyperOS. Если кнопки скрыты, проверьте системное разрешение показа поверх других приложений и настройки плавающих окон Game Turbo. POCO X8 Pro поставляется с HyperOS 3 на базе Android 16. [Справка Xiaomi](https://www.mi.com/global/support/faq/details/KA-676361/)

## Использование

- **Диалоги внизу** читает нижние 42% экрана и объединяет найденные блоки в одну реплику. Перевод запускается, когда реплика остаётся прежней при следующей проверке. Сохраняются последние 40 реплик с оригиналом и переводом.
- **Весь экран** распознаёт надписи по всему экрану и размещает переводы возле их координат. Размер шрифта и прозрачность регулируются в приложении.
- **Блоки** включает редактирование положения переведённого текста и временно приостанавливает распознавание. Перетащите блок или измените его размер двумя пальцами, затем нажмите **Готово**, чтобы возобновить перевод и снова передавать касания игре. **Любую кнопку «Блоки» или «Стоп» можно удерживать и затем перетаскивать**, чтобы переместить всю панель управления; короткое нажатие по-прежнему выполняет действие. Небольшая строка состояния показывает, почему перевода нет (текст не найден, модель не загружена или нет кадров захвата).
- **Словарь** содержит проверенные по опубликованным переводам варианты терминов. Формат редактирования — одна пара на строку, китайский оригинал и русский перевод через знак `=`. Источники приведены в [описании словаря](docs/MYSTIC-GLOSSARY.md).
- **Повышенная детализация OCR** обрабатывает изображение с более высоким пределом разрешения. При задержках увеличьте интервал распознавания. Повторные результаты берутся из кэша в памяти.

## Сеть и данные

По умолчанию снимки и распознанный текст обрабатываются на устройстве. ML Kit может связываться с Google для загрузки моделей и отправлять технические метрики по условиям SDK. История хранится в закрытом хранилище приложения. Её можно очистить на вкладке **История**. При переключении между сторонними приложениями захват продолжается. Пока открыт MysticTranslate, обработка приостанавливается. [Условия ML Kit](https://developers.google.com/ml-kit/terms)

Два режима включаются отдельным подтверждением в приложении:

- **Umi-OCR** отправляет изображение выбранной области на ваш HTTPS-сервер с Umi-OCR. Укажите базовый URL либо полный путь `/api/ocr`. Движок является адаптацией существующего Umi-OCR из исходного проекта.
- **Облако** отправляет текущую китайскую реплику, до трёх недавних реплик и словарь на выбранный OpenAI-совместимый HTTPS API. Укажите базовый URL, обычно с `/v1`, имя модели и ключ. Для всего экрана используется локальный перевод. Ключ хранится только в памяти процесса. После перезапуска оба сетевых режима выключены.

## Сборка

Требуются JDK 17 или 21, Android SDK Platform 36 и Build Tools 36.0.0, а также доступ к Google Maven и Maven Central. Укажите путь к SDK в `ANDROID_HOME` или через `sdk.dir` в локальном `local.properties`.

Windows PowerShell, для SDK из стандартного каталога:

```powershell
$env:ANDROID_HOME = "$env:LOCALAPPDATA/Android/Sdk"
.\gradlew.bat :mystic:testDebugUnitTest :mystic:lintDebug :mystic:assembleDebug
```

Linux и macOS:

```sh
./gradlew :mystic:testDebugUnitTest :mystic:lintDebug :mystic:assembleDebug
```

APK находится в `mystic/build/outputs/apk/debug/mystic-debug.apk`. Он подписан отладочным ключом. При смене подписи Android потребует удалить старую сборку. Удаление приложения стирает локальную историю и правки словаря.

## Проверка на телефоне

- Android 14, 15 и 16. Отказ в разрешениях и повторный старт, поворот экрана, остановка из оверлея, уведомления и индикатора Android.
- POCO X8 Pro. Отображение кнопок в игре, прохождение касаний, перемещение и масштабирование блоков, совпадение координат в альбомном режиме.
- Игра «Повелитель тайн». Скорость OCR, читаемость игровых шрифтов, переходы реплик, корректность терминов, перевод при отключённой сети после загрузки моделей.
- Umi-OCR и OpenAI-совместимый API. Проверка на своём HTTPS-сервере, выключение режима во время сеанса и отсутствие сетевого трафика игрового содержимого до согласия.

Если игра или системное окно защищают содержимое от захвата, система может показать пустой кадр. Приложение использует штатные разрешения Android.
